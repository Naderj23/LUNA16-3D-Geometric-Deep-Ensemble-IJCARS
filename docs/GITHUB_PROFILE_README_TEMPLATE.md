### Research Interests
- **Computer-Assisted Radiology & Thoracic CT Analysis:** Pulmonary nodule detection, false-positive reduction (FPRED), and volumetric 3D CT analysis on LIDC-IDRI / LUNA16.
- **3D Differential Geometry & White-Box Medical AI:** Scale-normalized 3D Hessian invariants (Frangi vesselness/blobness, Koenderink shape index), inward radial-gradient flux, and 26-ray antipodal Star-Ray order statistics.
- **Volumetric Deep Learning & Provenance-Audited Stacking:** 3D Axial-Coronal-Sagittal (ACS) residual networks, Center-Focused Multi-Scale Pyramid Pooling (CF-MSPP), Direct-FROC neural calibration, and scan-disjoint out-of-fold ensemble learning.
- **Forensic Benchmark Auditing & Reproducible Medical AI:** Scan-disjoint cross-validation, cluster-resampled bootstrap inference, and analytical prior-shift modeling.
