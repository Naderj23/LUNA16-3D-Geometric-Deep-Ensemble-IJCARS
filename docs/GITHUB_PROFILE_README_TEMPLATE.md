* **3D Differential Geometry & White-Box Medical AI:** Scale-normalized 3D Hessian invariants (Frangi vesselness/blobness, Koenderink shape index), inward radial-gradient flux, and 26-ray antipodal Star-Ray order statistics.

* **Forensic Benchmark Auditing & Reproducible Medical AI:** Scan-disjoint cross-validation, cluster-resampled bootstrap inference, and prior-shift modeling.
